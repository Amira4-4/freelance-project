## 🌟 Overview

**MahandesPro** is an end-to-end engineering marketplace and SaaS platform bridging real estate developers, contractors, and project owners with accredited engineering consultants and specialists across all disciplines:
- Civil & Structural Engineering
- Architectural & BIM Design
- MEP (Mechanical, Electrical, Plumbing)
- Interior Design & 3D Visualization
- Infrastructure, Surveying & Project Management

Built with **Premium SaaS aesthetic** (harmonious Cyan, shades of Royal & Deep Blues, and pure White), modern design tokens, interactive analytics via **Recharts**, and an **AI Engineering Assistant Engine**.

## 🚀 Key Features

### 1. Client & Developer Experience
* **Post Engineering Tenders:** Set scope, budget, CAD/BIM deliverables, and required building codes.
* **MahandesPro AI Project Architect:** Automatically generates technical requirements and recommends software (Revit, ETABS, AutoCAD).
* **Proposal Review & Acceptance:** Compare bids, review consultant cover letters, and accept offers with 1-click status transitions.
* **Direct Real-Time Chat:** Consult directly with engineers before and during project execution.
* **Bookmarking System:** Save favorite engineering consultants for upcoming bids.

### 2. Engineer & Consultant Workspace
* **Accreditation Profile:** Professional bio, syndicate licenses, hourly rates, and verified badges.
* **Interactive Portfolio Showcase:** Blueprints, structural models, calculations, and external links.
* **AI Profile Optimization Assistant:** AI-generated bio suggestions and actionable acceptance tips.
* **Proposal Submission:** Submit customized quotes and delivery schedules.
* **Availability Toggle:** Instantly toggle between "Available" and "Busy".

### 3. SaaS Executive Admin Console
* **Master-Detail Review Queue:** Review new consultant applications, inspect CVs, and verify licenses.
* **Approve / Decline Workflow:** Decline with actionable feedback notes to the applicant.
* **Visual Analytics (Recharts):** Monthly growth trends, category distributions, and project volumes.
* **Project Audit Directory:** Real-time table auditing all tenders and bids across the platform.

## 💻 Tech Stack

* **Core Framework:** React 19.2 + Vite 8
* **Styling & System:** Tailwind CSS 3.4 (with custom Cyan/Blue palette tokens)
* **Routing:** React Router DOM (HashRouter for GitHub Pages compatibility) + Route-based Code Splitting (`React.lazy`)
* **Charts & Analytics:** Recharts 3.1
* **Icons:** Lucide React
* **State & Persistence:** Context API + LocalStorage Data Access Layer with versioned seed keys

## 🛠️ Local Development & Build

### Prerequisites
* Node.js v18+ (tested on Node v20/v22)
* npm, pnpm, or yarn

### Installation
```bash
# 1. Clone repository
git clone https://github.com/Amira4-4/freelance-project.git
cd freelance-project

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

### Deploy to GitHub Pages
```bash
npm run deploy
```
